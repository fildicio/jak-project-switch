# T15 — `scripts/gen-dk-pipeline-table.py` → `PipelineTable.inc`

**Goal:** generate the C++ data for the T14 structs from `docs/deko3d/pipeline_table.json`,
so the table is never typed by hand.

**Create (2 files):**
- `scripts/gen-dk-pipeline-table.py` (python3, stdlib only, ~80 lines)
- `game/graphics/deko3d_renderer/PipelineTable.inc` (its output, committed)

**Script behavior:**
- Read the JSON (path relative to the repo root, found via `Path(__file__).parent.parent`).
- Map every `deko3d_state.depthCompareOp` / `blend` / sampler field to the T14 enum
  names. **Unknown value → print it and exit 1** (never silently default).
- Write:
  ```cpp
  // Generated by scripts/gen-dk-pipeline-table.py from docs/deko3d/pipeline_table.json.
  // Do not edit. (AI-assisted)
  static const dkpipe::PipelineDesc kPipelines[] = {
    {"P001", false, dkpipe::Compare::Always, false, dkpipe::Blend::Off},
    ...
  };
  static const dkpipe::SamplerDesc kSamplers[] = { ... };
  static_assert(sizeof(kPipelines) / sizeof(kPipelines[0]) == <pipeline_count>, "count");
  static_assert(sizeof(kSamplers) / sizeof(kSamplers[0]) == <sampler_count>, "count");
  ```
  (`depth_test` false → `Compare::Always`.)
- `--check` flag: regenerate in memory, exit 1 if it differs from the file on disk.

**Done-check:**
```sh
python3 scripts/gen-dk-pipeline-table.py && python3 scripts/gen-dk-pipeline-table.py --check && \
printf '#include "game/graphics/deko3d_renderer/PipelineTable.h"\n#include "game/graphics/deko3d_renderer/PipelineTable.inc"\nint main(){return 0;}\n' \
 | clang++ -std=c++17 -I. -fsyntax-only -Wall -x c++ - && echo compile-ok
```
