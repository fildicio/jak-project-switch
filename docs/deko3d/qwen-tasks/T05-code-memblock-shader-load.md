# T05 — Code memblock + load the splash shaders at init

**Goal:** `dkdev::init` creates a small code memblock and loads the embedded splash
shaders into `DkShader` objects. Nothing draws with them yet (T07 does).

**Edit (1 file):** `game/graphics/pipelines/dk_device.cpp`.

**Steps:**
1. Includes (after `<deko3d.h>`): `#include "dksh/splash_vert.h"` and `"dksh/splash_frag.h"`
   (generated by T04; arrays `splash_vert` / `splash_vert_size`, same for frag).
2. Constants near `kDataPool`: `constexpr uint32_t kCodePool = 64 * 1024;`
3. Statics: `DkMemBlock s_codeMem = nullptr; DkShader s_splashVsh, s_splashFsh; bool s_have_shaders = false;`
4. Helper in the anonymous namespace:
   ```cpp
   // loads one embedded .dksh: code section -> s_codeMem at *offset, control stays in place
   bool load_shader(DkShader* out, const uint8_t* blob, uint32_t size, uint32_t* offset)
   ```
   - A `.dksh` = header + control section + code section. Read the header like the
     official loader (`docs/deko3d-ref/examples/deko_examples/source/SampleFramework/CShader.cpp`):
     `struct DkshHeader { uint32_t magic, header_sz, control_sz, code_sz, programs_off, num_programs; };`
     `memcpy` it out of `blob`; fail (log) if `control_sz + code_sz > size`.
   - `*offset = align_up(*offset, DK_SHADER_CODE_ALIGNMENT)`; fail (log) if `*offset + code_sz > kCodePool`.
   - Copy **only the code section** to GPU memory:
     `memcpy((uint8_t*)dkMemBlockGetCpuAddr(s_codeMem) + *offset, blob + hdr.control_sz, hdr.code_sz)`.
   - The control section stays in CPU memory; the embedded array is static, so point at it:
     `DkShaderMaker sm; dkShaderMakerDefaults(&sm, s_codeMem, *offset); sm.control = blob; sm.programId = 0;`
     then `dkShaderInitialize(out, &sm)`; check `dkShaderIsValid(out)`, log on failure.
     (Fields verified in deko3d.h: `codeMem, control, codeOffset, programId`.)
   - `*offset += hdr.code_sz`.
5. In `init()`: add `kCodePool` to `need` in the heap check. After `s_dataMem` is made:
   `s_codeMem = make_block(kCodePool, DkMemBlockFlags_CpuUncached | DkMemBlockFlags_GpuCached | DkMemBlockFlags_Code, "code");`
   include it in the `if (!...)` failure check.
6. After the queue/cmdbuf are created: load both shaders with one shared `offset`;
   `s_have_shaders = both ok;` log `[dk] shaders: splash vert %u B, frag %u B, code used %u KB`.
   **A shader failure is not fatal**: log it, keep `s_have_shaders = false`, init still returns true.
7. `shutdown()`: destroy `s_codeMem` like the other blocks; reset `s_have_shaders`.
   (`DkShader` has no destroy function — check the header.)

**Done-check:** `scripts/ai/check-switch.sh jak1` → `PASS`.
