# T02 — `cmake/EmbedBinary.cmake`: turn a binary file into a C header

**Goal:** a CMake *script* (run with `cmake -P`) that embeds a compiled `.dksh` shader
into a header, so the NRO carries shaders inside it (no files on the SD card).

**Create (1 new file):** `cmake/EmbedBinary.cmake` (~30 lines).

**Inputs (passed with `-D`):** `IN` (binary path), `OUT` (header path), `NAME` (C identifier).

**Behavior:**
1. `file(READ "${IN}" hex HEX)`; fail with `message(FATAL_ERROR ...)` if `IN` is missing or empty.
2. Convert to `0xAB,` bytes: `string(REGEX REPLACE "([0-9a-f][0-9a-f])" "0x\\1," bytes "${hex}")`.
   Insert a newline every ~16 bytes for readability (optional).
3. Write `OUT`:
   ```c
   // Generated by cmake/EmbedBinary.cmake from <file name of IN>. Do not edit. (AI-assisted)
   #pragma once
   #include <stdint.h>
   alignas(256) static const uint8_t NAME[] = { ...bytes... };
   static const uint32_t NAME_size = <byte count>;
   ```
   `<byte count>` = string length of `hex` / 2.
4. Only rewrite `OUT` if the content changed (`file(WRITE)` to a temp, then
   `file(COPY_FILE ... ONLY_IF_DIFFERENT)` or compare first) — avoids needless rebuilds.

**Done-check (on the Mac, from repo root):**
```sh
cmake -DIN=docs/deko3d/uam-spike/tfrag3.vert.dksh -DOUT=/tmp/t.h -DNAME=tfrag3_vert \
  -P cmake/EmbedBinary.cmake && head -4 /tmp/t.h && grep -c 0x /tmp/t.h && \
  grep _size /tmp/t.h && stat -f%z docs/deko3d/uam-spike/tfrag3.vert.dksh
```
Expected: the `_size` value equals the `stat` byte count.
